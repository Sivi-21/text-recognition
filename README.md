# AI-Based Text Recognition System Using OCR

## Overview

This project is a basic Image/Text Recognition application that uses Optical Character Recognition (OCR) to extract text from images.

## Features

* Detects text from images
* Uses EasyOCR pre-trained AI model
* Displays extracted text with confidence scores
* Beginner-friendly implementation

## Technologies Used

* Python
* EasyOCR
* OpenCV
* Matplotlib

## Project Structure

AI-Text-Recognition/
├── app.py
├── sample_image.png
├── README.md
├── requirements.txt

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
